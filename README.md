# Braverman Bot

Telegram-бот с тестом Бравермана (упрощённая версия, 48 вопросов) —
определяет вероятный дефицит четырёх нейромедиаторов:

- 🧠 Дофамин — энергия, мотивация, концентрация
- 🧠 Ацетилхолин — память, ясность мышления, креативность
- 🧠 ГАМК — спокойствие, стрессоустойчивость
- 🧠 Серотонин — настроение, сон, уверенность

В конце бот показывает процент по каждому веществу и общие
рекомендации (продукты, добавки, привычки) для двух наиболее
выраженных дефицитов. Рекомендации не привязаны к конкретным
товарам — это общий совет с дисклеймером «не является медицинской
диагностикой».

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env   # и вписать туда токен бота от @BotFather
python bot.py
```

## Структура

- `test_data.py` — вопросы, категории, рекомендации, тексты.
- `bot.py` — логика бота (aiogram 3, FSM, инлайн-кнопки).

## Как расширить

- Добавить вопросы: дописать в список `QUESTIONS` в `test_data.py`
  (пара `(текст, категория)`, категории: `dopamine`, `acetylcholine`,
  `gaba`, `serotonin`).
- Привязать рекомендации к конкретным товарам магазина: заменить
  тексты в `RECOMMENDATIONS` на карточки товаров/ссылки.
- Сохранять результаты пользователей: добавить запись в БД в
  `finish_test()` перед отправкой ответа.
